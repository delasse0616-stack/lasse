# Mini Apps

의존성 없는 단일 HTML 파일 모음. 빌드 도구도, 설치도 필요 없습니다.
파일을 브라우저로 열거나 더블클릭하면 바로 실행됩니다.

## 실행 방법

```
git clone <this-repo>
```

받은 폴더에서 원하는 `.html` 파일을 브라우저로 열면 됩니다.
`index.html`을 열면 세 앱으로 이동하는 카드 목록이 나옵니다.

## 앱 목록

### 🍅 Focus Timer — `focus-timer.html`

뽀모도로 타이머와 할 일 목록.

- 집중 25분 / 휴식 5분 / 긴 휴식 15분 모드
- 원형 진행바, 뽀모도로 4회마다 긴 휴식으로 자동 전환
- 오늘 완료한 뽀모도로 수와 집중 시간(분) 기록
- 완료 시 알림음 + 브라우저 알림
- 할 일에 "현재 집중 대상"을 지정하면 완료한 뽀모도로가 해당 항목에 쌓임
- `Space` 키로 시작/일시정지
- 진행 상황과 할 일은 `localStorage`에 저장

### 🔮 Kaleidoscope Pad — `kaleidoscope.html`

마우스·터치로 그리면 대칭 만화경으로 펼쳐지는 캔버스.

- 대칭 수(2–24), 굵기(1–40), 잔상(0–20) 조절
- 거울 모드 / 무지개 색 토글
- 지우기, PNG로 저장

### 🎮 2048 — `2048.html`

같은 숫자를 합쳐 2048을 만드는 고전 슬라이딩 퍼즐.

- 방향키 · `WASD` · 모바일 스와이프 지원
- 타일 이동/합치기 애니메이션
- 최고 점수 `localStorage` 저장
- 승리 / 게임 오버 화면

## 공통 사항

- 외부 라이브러리·네트워크 요청 없음, 완전 오프라인 동작
- 다크 테마, 모바일 화면 대응
- 최신 브라우저(Chrome, Edge, Firefox, Safari)에서 동작
